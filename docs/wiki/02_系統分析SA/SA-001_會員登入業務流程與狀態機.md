# SA-001: 會員登入業務流程與狀態機分析

## 📊 業務流程圖 (Business Flowchart)

```mermaid
flowchart TD
    Start([使用者發起登入]) --> InputCheck{欄位格式檢查}
    InputCheck -- 不合法 --> Err400[回傳 400 Bad Request]
    
    InputCheck -- 合法 --> QueryUser[查詢使用者資料<br/>users 表]
    QueryUser --> UserExist{帳號是否存在?}
    
    UserExist -- 否 --> AuthFail[增加模糊失敗延遲<br/>回傳 401 憑證錯誤]
    
    UserExist -- 是 --> StatusCheck{帳號狀態檢查}
    StatusCheck -- LOCKED / DISABLED --> Err403[回傳 403 帳號已鎖定]
    
    StatusCheck -- ACTIVE --> PwdVerify{Argon2 密碼比對}
    PwdVerify -- 不相符 --> IncFail[failed_attempts + 1]
    IncFail --> Over5{連續失敗 >= 5次?}
    Over5 -- 是 --> LockAccount[狀態改為 LOCKED<br/>設定 locked_until = now+15m]
    Over5 -- 否 --> Err401[回傳 401 憑證錯誤]
    LockAccount --> Err401
    
    PwdVerify -- 相符 --> ResetFail[failed_attempts = 0<br/>更新 last_login_at]
    ResetFail --> GenToken[生成 Access / Refresh Token]
    GenToken --> Success([回傳 200 OK 與 Token])
```

---

## 🔄 帳號狀態機 (User Account State Machine)

```mermaid
stateDiagram-v2
    [*] --> PENDING_VERIFICATION: 註冊帳號
    PENDING_VERIFICATION --> ACTIVE: Email 驗證成功
    ACTIVE --> LOCKED: 連續 5 次密碼錯誤
    LOCKED --> ACTIVE: 15 分鐘鎖定超時 或 管理員解鎖
    ACTIVE --> DISABLED: 違反服務條款 / 用戶主動停用
    DISABLED --> ACTIVE: 管理員手動復權
    DISABLED --> [*]: 帳號永久刪除 (GDPR)
```

## 📋 業務規則清單 (Business Rules)

| 規則代碼 | 規則名稱 | 詳細描述 |
| :--- | :--- | :--- |
| **BR-AUTH-01** | 密碼雜湊防護 | 密碼儲存一律採用 **Argon2id** 演算法，禁止以明文或 MD5/SHA1 儲存。 |
| **BR-AUTH-02** | 帳號枚舉防護 | 不論是帳號不存在或密碼錯誤，一律回傳統一錯誤碼 `AUTH_INVALID_CREDENTIALS`，防範枚舉攻擊。 |
| **BR-AUTH-03** | 失敗次數歸零 | 只要有一次登入成功，立即將 `failed_login_attempts` 重設為 0。 |
| **BR-AUTH-04** | 雙 Token 輪轉 | Access Token (15 分鐘) 無狀態，Refresh Token (7 天) 採白名單/版本號控制。 |
